WEFNC Nexus Analysis for Agricultural Systems

Lalit Kumar Rolaniya

Introduction

The wefnexus package provides a comprehensive toolkit for analyzing Water-Energy-Food-Nutrient-Carbon (WEFNC) nexus interactions in agricultural production systems. This vignette demonstrates a complete workflow using a conservation agriculture dataset from western Rajasthan, India.

If you have replicated field data and want the whole analysis in one step, jump to Section 7. Sections 1 to 6 show the individual modules.

6. Nexus Integration

Every treatment in this trial received the same starter dose of 20 kg N/ha, so partial factor productivity would only mirror yield. The nutrient dimension therefore uses internal N utilization efficiency (nutrient_metric = "iue"), and carbon is scored per kg of grain.

# Full Nexus Summary
ns <- nexus_summary(
  yield = d$grain_yield,
  water_consumed = d$total_water,
  energy_input = d$energy_input,
  energy_output = e_out,
  n_applied = d$n_applied,
  n_uptake = d$n_uptake,
  carbon_emission = d$ghg_emission,
  treatment_names = d$treatment,
  nutrient_metric = "iue",
  carbon_basis = "intensity"
)

Objective weights and TOPSIS ranking

Equal weights are a value judgement. nexus_weights() derives weights from the data (entropy, CRITIC or PCA), and nexus_topsis() ranks treatments on raw indicators in their own units.

ind <- data.frame(
  WUE = ns$WUE_kg_mm,
  EUE = ns$EUE_ratio,
  Yield = ns$yield_kg_ha,
  IUE = ns$IUE_kg_kgN,
  CI = ns$carbon_intensity
)
benefit <- c(TRUE, TRUE, TRUE, TRUE, FALSE)  # lower carbon intensity is better

rbind(
  entropy = nexus_weights(ind, "entropy", benefit),
  critic  = nexus_weights(ind, "critic", benefit),
  pca     = nexus_weights(ind, "pca", benefit)
)

Is the ranking robust?

A recommendation is more convincing when it does not depend on one choice of weights. nexus_rank_compare() ranks the treatments eight ways (composite index and TOPSIS, each with equal, entropy, CRITIC and PCA weights) and measures agreement with Kendall’s W (0 = none, 1 = identical rankings).

rc <- nexus_rank_compare(ind, benefit = benefit,
                         treatment_names = d$treatment)
rc

Synergies and trade-offs

nexus_tradeoff() returns the correlation matrix with p-values attached; plot_tradeoff() draws it. Carbon intensity is lower-is-better, so pass benefit to orient the indicators: blue then always means the two improve together (synergy) and red means one improves as the other gets worse (trade-off).

plot_tradeoff(nexus_tradeoff(ind), benefit = benefit)

7. One-call workflow for replicated trials

arid_pulse_trial holds plot-level data from a randomized complete block design with three replications. nexus_analysis() computes plot-level indicators, runs ANOVA, builds the nexus index from treatment means and ranks treatments by TOPSIS.

data(arid_pulse_trial)
res <- nexus_analysis(
  arid_pulse_trial,
  treatment = "treatment", block = "replication",
  yield = "grain_yield", water = "total_water",
  energy_in = "energy_input", energy_out = "energy_output",
  emission = "ghg_emission", n_uptake = "n_uptake",
  weights = "entropy", carbon_basis = "intensity"
)
res

Figures for the manuscript

Every result has a plot() method that returns a ggplot2 object, so you can add your own theme or labels and save it with ggplot2::ggsave().

plot(res$anova, response = c("grain_yield", "WUE", "EUE", "CI"),
     labels = c(grain_yield = "Grain yield (kg/ha)",
                WUE = "WUE (kg/ha/mm)",
                EUE = "Energy use efficiency",
                CI = "Carbon intensity (kg CO2-eq/kg)"),
     ncol = 2)

plot(res)                    # one radar per treatment

plot(res, which = "topsis")
